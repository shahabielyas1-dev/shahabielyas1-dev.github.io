۱. بارگذاری فرم محاسبه‌شده

فایل qc-print-designer.html باید کنار alis-print.html و تصویر alis-form-revision5-a5.png باشد. با Live Server اجرا کن. اگر URL اصلی آنلاین است، فقط پارامترهای آن استفاده می‌شوند و پیش‌نمایش از فایل محلی همین پوشه ساخته می‌شود.

۲. انتخاب نوشته برای تنظیم

برای انتخاب، روی نام فیلد بزن یا مستقیماً روی نوشته در پیش‌نمایش کلیک کن.

۳. موقعیت و اندازه

روی نوشته انتخاب‌شده در صفحه بکش تا جابه‌جا شود. دستگیره گوشه پایین-چپ آن را برای تغییر اندازه بکش. تغییرات فقط در همین پیش‌نمایش اعمال می‌شوند.

۴. خروجی تنظیمات

برای دائمی‌کردن تغییرات، CSS خروجی را در انتهای بخش style فایل alis-print.html و قبل از ‎</style>‎ قرار بده. منطق محاسبات و دریافت قیمت را تغییر نده.
